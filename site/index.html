Training uses your CPU and may take several minutes. Each run starts fresh. Download weights before leaving; nothing is saved automatically. Weights can memorize training text, so treat the exported file as private if your text is private.

This learns text patterns, not reliable answers about your documents. Small or repeated datasets can give deceptively low validation loss. For larger local runs, follow the Python custom-data guide ↗.
